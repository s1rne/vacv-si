# Предсказание индекса селективности против вируса оспы

Решение задачи «Поиск лекарств» (Nuclear IT Hack, ноябрь 2026, лаборатория хемоинформатики и молекулярного моделирования ИИКС НИЯУ МИФИ). По SMILES-записи молекулы предсказывается индекс селективности SI = CC50 / IC50 против вируса осповакцины (штамм VACV).

Соревнование: [Molecular Activity Prediction](https://www.kaggle.com/competitions/molecular-activity-prediction-hack), метрика MSE на исходной шкале SI.

## Запуск

```bash
uv sync --frozen
PYTHONPATH=. uv run python scripts/cv.py --profiles baseline hybrid --seeds 7 --start-seed 3
PYTHONPATH=. uv run python scripts/submit.py --profile hybrid --seeds 7
uv run pytest                           # тесты
```

Данные соревнования кладутся в `data/raw/kaggle/` (`train.csv`, `test.csv`, `sample_submit.csv`).
Готовые внешние признаки находятся в отслеживаемой папке `data/processed/`.
Для их повторной сборки: `uv run python -m vacv.cli all`; для воспроизведения текущего
результата повторный сбор не нужен и может изменить данные источников.

На macOS LightGBM нужен OpenMP. Если `libomp` не установлен глобально, использованная
в проверках локальная библиотека из wheel scikit-learn подключается только к процессу:

```bash
export DYLD_LIBRARY_PATH="$(uv run python -c 'from pathlib import Path; import sklearn; print(Path(sklearn.__file__).parent / ".dylibs")')${DYLD_LIBRARY_PATH:+:$DYLD_LIBRARY_PATH}"
```

Сабмит проверяется на конечные неотрицательные значения, уникальные ID и совпадение
с `sample_submit.csv`. Рядом сохраняется JSON с профилем, числом seed и SHA256 CSV.

## Устройство решения

### Что говорит задача, а что данные

Метрика квадратичная и считается на исходной шкале SI, где примерно четверть обучающей выборки равна ровно 10000. Организаторы подтвердили, что это не измерение, а отметка «IC50 отсутствует, соединение против VACV неактивно» ([docs/organizers.md](docs/organizers.md)). Отсюда устройство прогноза: ошибка определяется прежде всего тем, отнесено ли соединение к неактивным. Промах здесь стоит порядка 10⁸, ошибка в разы на активном соединении — порядка 10². Оптимальный по квадратичной метрике прогноз это условное среднее:

```
SI = p · 10000 + (1 − p) · среднее SI активных
```

где `p` — вероятность неактивности.

### Откуда берётся вероятность

| Источник | Что использует | Вклад |
|---|---|---|
| Контекстный ExtraTrees | штамм, культура, обозначение соединения, внешние признаки; leaf=1, max_features=0.5 | 50% |
| Kernel ridge | квадрат Tanimoto по Morgan, совпадение группы и статуса литературного совпадения; alpha=0.3 | 50% |

Это профиль `hybrid`, используемый по умолчанию. Kernel ridge обучается на бинарной
метке `SI == 10000`; вероятность ограничивается [0, 1]. Категории и матрица ядра
строятся только по обучающей части. Равные веса фиксированы после исследовательских
разбиений 0–2; проверка проводится также на разбиениях 3–5 и по остовам.
Итог — среднее по семи seed контекстного леса и детерминированная kernel-модель.

Исходный профиль `baseline` (0.3 контекст + 0.7 LightGBM с групповыми долями) сохранён
для сравнения. В нём обучающая строка входит в собственную групповую долю; это
расхождение между обучением и предсказанием. Внешняя контрольная часть в расчёт
долей не входит. Вариант `crossfit` исключает свою строку через внутренние фолды,
но в проведённом сравнении оказался хуже. `hybrid` групповые доли не использует.

Группа «штамм + культура» отвечает публикации, из которой взято соединение, и покрывает 98.5% тестовых строк. Знание группы снижает неопределённость метки с 0.821 до 0.316 бита: внутри одной публикации серия соединений обычно либо активна, либо нет.

### Открытые базы

Задание требует собрать данные из открытых источников. Соединения выборки взяты из опубликованных статей, поэтому те же молекулы находятся в ChEMBL и PubChem вместе с измеренными IC50 и CC50. Собранная база описана в [docs/dataset.md](docs/dataset.md), источники и лицензии — в [docs/data_sources.md](docs/data_sources.md).

Данные используются двумя способами:

1. Где значение SI восстанавливается из литературы, оно заменяет прогноз модели. Проверка на обучающей выборке: медианная ошибка в логарифме 0.00, совпадение бит в бит у 58%, коэффициент Спирмена 0.92.
2. Признаки присутствия соединения в базах (близость к ближайшему измеренному соединению, число записей, лучшие IC50 и CC50) идут в модель. Среди найденных в литературе доля неактивных 1.6%, среди ненайденных — 40.6%.

Колонки `CC50_uM` и `IC50_uM_VACV` из файлов соревнования не используются: правила это запрещают, и загрузчик [vacv/dataset.py](vacv/dataset.py) удаляет их сразу после чтения.

## Оценка

Две схемы кросс-проверки, обе с метрикой соревнования:

- **случайное разбиение** — ориентир для лидерборда: тестовая выборка не отделена от обучающей по химии, 98.5% групп общие, девять молекул совпадают полностью;
- **разбиение по остовам Мурко** — стресс-проверка переноса на другие химические серии;
  это не гарантированная нижняя граница качества на новых данных.

Исторические результаты исходного решения на публичном лидерборде:
11.35M → 9.29M → 8.59M → 7.56M → 7.49M. Новый `hybrid` на Kaggle ещё не отправлен.

CV и сабмит используют единый путь `vacv/inference.py`, включая внешние признаки
и литературные подстановки. AUC считается по вероятности точной метки `SI == 10000`,
а основная метрика — MSE итогового прогноза без удаления выбросов. Настоящий SI=36066.667
остаётся активным наблюдением. CSV построчных OOF и JSON метрик сохраняются в `outputs/`.
Повторные разбиения используют те же 320 объектов: они проверяют устойчивость, но
не заменяют независимую тестовую выборку и не гарантируют результат на лидерборде.

Проведённые эксперименты и выводы по каждому: [experiments/README.md](experiments/README.md).
