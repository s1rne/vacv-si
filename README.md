# Предсказание индекса селективности против вируса оспы

Решение задачи «Поиск лекарств» (Nuclear IT Hack, ноябрь 2026, лаборатория хемоинформатики и молекулярного моделирования ИИКС НИЯУ МИФИ). По SMILES-записи молекулы предсказывается индекс селективности SI = CC50 / IC50 против вируса осповакцины (штамм VACV).

Соревнование: [Molecular Activity Prediction](https://www.kaggle.com/competitions/molecular-activity-prediction-hack), метрика MSE на исходной шкале SI.

## Запуск

```bash
uv sync
uv run python -m vacv.cli all          # сбор данных из открытых баз и сборка набора
PYTHONPATH=. uv run python scripts/cv.py       # кросс-проверка
PYTHONPATH=. uv run python scripts/submit.py   # файл ответа в outputs/submission.csv
uv run pytest                           # тесты
```

Данные соревнования кладутся в `data/raw/kaggle/` (`train.csv`, `test.csv`, `sample_submit.csv`).

## Устройство решения

### Что говорит задача, а что данные

Метрика квадратичная и считается на исходной шкале SI, где примерно четверть обучающей выборки равна ровно 10000. Организаторы подтвердили, что это не измерение, а отметка «IC50 отсутствует, соединение против VACV неактивно» ([docs/organizers.md](docs/organizers.md)). Отсюда устройство прогноза: ошибка определяется прежде всего тем, отнесено ли соединение к неактивным. Промах здесь стоит порядка 10⁸, ошибка в разы на активном соединении — порядка 10². Оптимальный по квадратичной метрике прогноз это условное среднее:

```
SI = p · 10000 + (1 − p) · среднее SI активных
```

где `p` — вероятность неактивности.

### Откуда берётся вероятность

| Источник | Что использует | Вклад |
|---|---|---|
| Контекст записи | штамм, культура клеток, обозначение соединения | косвенно указывает на публикацию-источник |
| Групповая модель | строение молекулы, доля неактивных в группе, признаки присутствия в открытых базах | основной источник |

Группа «штамм + культура» отвечает публикации, из которой взято соединение, и покрывает 98.5% тестовых строк. Знание группы снижает неопределённость метки с 0.821 до 0.316 бита: внутри одной публикации серия соединений обычно либо активна, либо нет.

### Открытые базы

Задание требует собрать данные из открытых источников. Соединения выборки взяты из опубликованных статей, поэтому те же молекулы находятся в ChEMBL и PubChem вместе с измеренными IC50 и CC50. Собранная база описана в [docs/dataset.md](docs/dataset.md), источники и лицензии — в [docs/data_sources.md](docs/data_sources.md).

Данные используются двумя способами:

1. Где значение SI восстанавливается из литературы, оно заменяет прогноз модели. Проверка на обучающей выборке: медианная ошибка в логарифме 0.00, совпадение бит в бит у 58%, коэффициент Спирмена 0.92.
2. Признаки присутствия соединения в базах (близость к ближайшему измеренному соединению, число записей, лучшие IC50 и CC50) идут в модель. Среди найденных в литературе доля неактивных 1.6%, среди ненайденных — 40.6%.

Колонки `CC50_uM` и `IC50_uM_VACV` из файлов соревнования не используются: правила это запрещают, и загрузчик [vacv/dataset.py](vacv/dataset.py) удаляет их сразу после чтения.

## Оценка

Две схемы кросс-проверки, обе с метрикой соревнования:

- **случайное разбиение** — ориентир для лидерборда: тестовая выборка не отделена от обучающей по химии, 98.5% групп общие, девять молекул совпадают полностью;
- **разбиение по остовам Мурко** — честная нижняя оценка на новых химических сериях.

Ход результатов на публичном лидерборде: 11.35M → 9.29M → 8.59M → 7.56M → 7.49M.

Проведённые эксперименты и выводы по каждому: [experiments/README.md](experiments/README.md).
