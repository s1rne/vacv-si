# Решение команды СЫРНАЯ ПЛАНЕТА 4.0

Кейс «Поиск лекарств», Nuclear IT Hack 2026: прогноз индекса селективности SI VACV по структуре SMILES и экспериментальному контексту. Команда **СЫРНАЯ ПЛАНЕТА 4.0 | МИСИС**.

**Итоговый подтверждённый Public MSE: 1 710 149,26680**, файл `submission-pair-delta-v4.csv`. Успешная отправка 7 ноября, повторно проверена на странице Kaggle 8 ноября 2026 года. Private score неизвестен; место в таблице меняется.

[Презентация нашего подхода](https://docs.google.com/presentation/d/1HrH1peRyxmVezEGztY1Z67ZzPIGDyyrP3Dabp8eE13Y/edit?usp=sharing)

## Итоговая модель

**Pair-delta v4 / Ridge-log**: бинарные Morgan radius 2 / 2048, обучение разностей log1p(SI) между близкими структурами в одинаковых strain/Culture, Ridge alpha=10 без intercept, симметризация направлений. Прогноз относительно до трёх близких обучающих опор; при отсутствии подходящих опор — структурный log-KNN. Все 320 исходных train_v2 targets сохраняются, включая 36 066,667; неактивность имеет target 0.

Итоговая модель не использует внешние метки, подстановки известных ответов, конкурсные CC50_uM/IC50_uM_VACV, их пропуски или производные. Предобученные CheMeleon/TabICL исследованы отдельно и для воспроизведения финала не нужны.

## Воспроизвести отправленный CSV

```sh
uv sync --group dev
# Официальный ZIP Kaggle с train_v2.csv, test.csv и sample_submit.csv:
uv run python scripts/import_competition_v2.py /path/to/molecular-activity-prediction-hack.zip
PYTHONPATH=. uv run python scripts/reproduce_final.py
```

Скрипт обучается на всех train_v2, сохраняет `outputs/submission-pair-delta-v4.csv` и отчёт проверки, сравнивает прогнозы с сохранённым отправленным файлом. Существующий выходной CSV не перезаписывается. Загрузка в Kaggle выполняется отдельно: эта команда только локальная.

Сохранённый отправленный файл: [CSV](experiments/results/v4-pair-delta-submission/submission-pair-delta-v4.csv). SHA-256:
`cbd1b6c1e7ebb858c9ca9bda38dbc24392c7ef81271228ef4edce96edd87ab60`.

Численное совпадение нового CSV с отправленным подтверждает воспроизведение прогнозов. Kaggle score относится к сохранённой успешной отправке; локальный запуск не вычисляет скрытые ответы Kaggle. Различия версий библиотек могут менять последние десятичные знаки, поэтому проверяются как значения, так и хеши.

## Восстановление базы из интернета

Отдельное направление команды — восстановление полной базы по открытым интернет-источникам. Материалы Z-Code из ветки `zcode/max-lb` сохранены в папке [restoration/zcode](restoration/zcode/README.md): таблицы, исследовательские скрипты и версия сборки данных. Здесь зафиксировано наличие материалов; их корректность в рамках финальной интеграции повторно не проверялась. Итоговый Kaggle-сабмит v4 воспроизводится отдельно.

## Навигация

- `scripts/reproduce_final.py` — актуальное воспроизведение финального сабмита.
- `experiments/v4_pair_delta.py` — алгоритм и исходный поиск четырёх вариантов.
- `experiments/results/` — OOF, метрики, протоколы, аудиты и сохранённые CSV.
- `docs/v4-model-research.md`, `docs/v5-results.md`, `docs/v6-research.md`, `docs/v8-nested-validation.md`, `docs/v9-backend-validation.md`, `docs/v10-spec-review.md` — подробные этапы исследования.
- `vacv/sources/`, `vacv/cli.py`, `data/processed/`, `docs/data_sources.md` — отдельная работа по сбору и проверке открытых данных; эти метки не входят в финальную v4.
- `scripts/submit.py`, `scripts/submit_checkpoint.py`, CheMeleon/TabICL и исторические hybrid-профили — исследовательские/исторические пути, не финальный v4.

Конкурсные исходные таблицы и локальные окружения не коммитятся. Зависимости закреплены в `uv.lock`; протоколы экспериментов дополнительно фиксируют хеши входных данных, кода и версии библиотек.
