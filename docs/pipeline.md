# Пайплайн сбора данных

Стадии, каждая читает файл предыдущей с диска. Запуск целиком: `uv run python -m vacv.cli all`
(нужен интернет и несколько часов запросов к API; готовые таблицы лежат в `data/processed/`,
поэтому модель воспроизводится и без этого).

| команда | что делает |
|---|---|
| `vacv.cli fetch` | запрашивает ChEMBL и PubChem BioAssay, включая сбор по соединениям соревнования; ключи `--source X`, `--refresh` |
| `vacv.cli curate` | стандартизация структур RDKit, перевод единиц в мкМ, учёт отбракованных записей |
| `vacv.cli build` | сопоставляет IC50 с CC50, считает SI, пишет таблицы и карточку данных |
| `vacv.cli match` | пересечение с файлами соревнования в `data/raw/kaggle/` |
| `vacv.cli presence` | признаки «что известно об этом соединении в открытых базах» для каждого соединения соревнования |
| `vacv.cli coverage` | подбирает правило сопоставления записей и проверяет его на обучающей выборке |
| `vacv.cli validate` | схема, SMILES, единицы, дубликаты, согласованность SI, доля записей с DOI |

## Файлы

| путь | содержание |
|---|---|
| `data/raw/<источник>/` | необработанные ответы API, кэш по адресу запроса (в git не входит) |
| `data/interim/measurements.csv.gz` | одно измерение на строку, все источники |
| `data/interim/curated.csv.gz` | то же после стандартизации и перевода единиц |
| `data/processed/vacv_si.csv` | итоговая база: `smiles, ic50, cc50, si, doi` и происхождение записи |
| `data/processed/vacv_si_strict.csv` | пары из одной публикации и одной клеточной линии |
| `data/processed/vacv_si_measured.csv` | записи, где ни IC50, ни CC50 не цензурированы: для обучения |
| `data/processed/competition_open_data_lookup.csv` | значение SI из открытых баз для каждого соединения соревнования и решение, подставлять ли его |
| `data/processed/competition_presence.csv` | признаки присутствия соединения в открытых базах и ближайшие измеренные соседи |
| `data/interim/competition_molecules.csv` | соединение соревнования и найденная молекула ChEMBL |
| `data/interim/inactive.csv.gz` | записи про вирус осповакцины с пометкой «Not active» вместо числа |

Карточка данных `docs/dataset.md` генерируется сборкой, вручную её не правят.

## Правило восстановления значения из открытых баз

Соединения выборки взяты из опубликованных статей, поэтому те же молекулы лежат в ChEMBL и PubChem
с измеренными IC50 и CC50. `vacv/recover.py` выбирает для соединения одну антивирусную запись и одну
запись цитотоксичности из одной публикации, предпочитая клеточную линию из поля `Culture`, затем
конечную точку CC50 перед MCC, затем цензурированную запись. Значение берётся так, как его напечатал
источник: пересчёта `ug/mL` в микромоли организаторы не делали.

`vacv/coverage.py` проверяет правило на обучающей выборке и читает из файла соревнования только
целевую колонку `SI VACV`: колонки `CC50_uM` и `IC50_uM_VACV` не читаются нигде, кроме диагностики
`vacv/exact_si.py`, и за этим следит `tests/test_forbidden_columns.py`. Результат проверки по
группам (уровень сопоставления и правило парности) определяет колонку `substitute_recommended`:
подставляем значение только там, где группа на обучении показала выигрыш по метрике соревнования.
При кросс-проверке решение пересчитывается внутри фолда (`literature.fold_table`).

Если запись говорит «Not active» против вируса вместо числа, именно так у организаторов пустеет
колонка IC50, и такое соединение неактивно. В `train_v2.csv` его SI равен 0, в первой версии
файла стояло 10000. Внутри пайплайна неактивным остаётся 10000, загрузчик понимает обе версии.

## Стандартизация

Канонизация таутомеров включена: на 48 077 уникальных SMILES текущей выгрузки это стоит 8,4 мс на
структуру (около 400 с) против 1,9 мс без неё, поэтому остаётся. `curate --no-tautomer` выключает
её. Канонизатор таутомеров RDKit по умолчанию стирает стереохимию, `vacv/curate.py` это запрещает.

Файлы соревнования для сборки базы не нужны. Положите `train.csv` в `data/raw/kaggle/` (или
запустите `scripts/fetch_competition.py`), чтобы получить отчёт о пересечении; ключ
`--include-competition` добавляет их измерения в промежуточную таблицу, а в `data/processed/` они не
попадают.

Источники, отклонённые источники и лицензии: `docs/data_sources.md`.
