# Восстановление базы Z-Code

Снимок материалов восстановления полной базы по открытым интернет-источникам из ветки `zcode/max-lb`, commit `0e132f9f0bbff69e98c33f1b153f991ca1644dc1`.

- `data/processed/` — сохранённые таблицы восстановления и происхождения данных.
- `experiments/` — исходные исследовательские скрипты ветки.
- `vacv/article_lookup.py` — версия сборки/подстановок из этой ветки.

Материалы сохранены отдельно как история работы Z-Code. В этой задаче проверено наличие файлов; корректность восстановления, полнота, совместимость измерений и допустимость всех исторических методов не проверялись. Снимок не подключён к итоговой модели v4. Исходники следует запускать в контексте исходного commit, а не как самостоятельный установленный пакет.
