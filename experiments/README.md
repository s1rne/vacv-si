# Эксперименты

Каждый скрипт запускается как `PYTHONPATH=. uv run python experiments/<имя>.py` и печатает таблицу.
Везде метрика соревнования: MSE на исходной шкале SI. Два разбиения: по остовам Мурко (честная
оценка на новых химических сериях) и случайное (ближе к устройству тестовой выборки).

| скрипт | вопрос | вывод |
|---|---|---|
| `grid.py` | как оценивать средний SI активных | не важно: константа, регрессия в логарифме и регрессия на исходной шкале дают 14.69–14.75M. Всё решает классификатор неактивных |
| `classifier.py` | какая модель и какие признаки | ExtraTrees лучше LightGBM, случайного леса, SVM и логистической регрессии: AUC 0.846 против 0.804–0.832 на остовах |
| `context.py` | помогают ли strain, Culture, Title | да, и сильно: контекст без структуры даёт AUC 0.882 против 0.846 у структуры. Внутри одной публикации серия соединений обычно либо активна, либо нет |
| `blend.py` | как соединить структуру и контекст | смешивать вероятности, а не признаки. Лучший вес 0.2 структуры: MSE 14.04M против 16.93M у структуры и 14.16M у контекста |
| `tuning.py` | категории или tf-idf для контекста | категории. Tf-idf хуже на остовах (15.21M против 13.97M) |
| `calibration.py`, `nested.py` | помогает ли калибровка вероятности | нет. На тех же данных изотоническая калибровка выглядит выигрышной (11.75M), но при честной вложенной проверке проигрывает (14.94M). Платт в пределах шума |
| `endpoint_cv.py` | как предсказываются IC50 и CC50 по внешнему корпусу | CC50 лучше IC50 (RMSE 0.68 против 0.85 на случайном разбиении). Цензурированный лосс AFT проигрывает на точных значениях и выигрывает в четыре раза на цензурированных |
| `inactive_transfer.py` | переносится ли метка «IC50 не определена» на заглушку SI = 10000 | нет. Внутри корпуса AUC 0.954, на выборке соревнования 0.507. Неактивность это свойство серии и протокола, а не строения |
| `multitask_si.py` | можно ли собрать SI из двух голов | нет: 33.9M против 10.3M у блендинга. Отдельно видно, что оценка среднего SI активных на этой метрике не решает ничего |
| `multitask_stack.py`, `multitask_seeds.py` | помогают ли выходы голов как признаки блендинга | чуть-чуть и только внутри признаков: AUC 0.965 → 0.967 на случайном разбиении, MSE в пределах разброса по затравкам. Как источник смеси вес 0.0 |

Итог для пайплайна: ExtraTrees на структуре и на контексте, смешивание вероятностей с весом 0.2,
условное среднее с константой для активных, без калибровки. Разложение SI на два эндпоинта
измерено и отклонено, подробности в `docs/multitask.md`.
