# Эксперименты

Каждый скрипт запускается как `PYTHONPATH=. uv run python experiments/<имя>.py` и печатает таблицу.
Везде метрика соревнования: MSE на исходной шкале SI. Два разбиения: случайное и по остовам Мурко.

Какое из них читать, установлено отдельно (`docs/validation.md`, разделы 2 и 4): обучение и тест
неразличимы состязательной валидацией (AUC 0.51), случайная кросс-проверка ранжирует поколения
модели так же, как лидерборд (Spearman +1.00), разбиение по остовам не ранжирует ничего
(−0.50). Поэтому модель отбирается по случайному разбиению, а оценка по остовам читается как
прогноз на новой химической серии.

## Отбор модели

| скрипт | вопрос | вывод |
|---|---|---|
| `grid.py` | как оценивать средний SI активных | не важно: константа, регрессия в логарифме и регрессия на исходной шкале дают 14.69–14.75M. Всё решает классификатор неактивных |
| `classifier.py` | какая модель и какие признаки | ExtraTrees лучше LightGBM, случайного леса, SVM и логистической регрессии: AUC 0.846 против 0.804–0.832 на остовах |
| `context.py` | помогают ли strain, Culture, Title | да, и сильно: контекст без структуры даёт AUC 0.882 против 0.846 у структуры. Внутри одной публикации серия соединений обычно либо активна, либо нет |
| `blend.py` | как соединить структуру и контекст | смешивать вероятности, а не признаки. Лучший вес 0.2 структуры: MSE 14.04M против 16.93M у структуры и 14.16M у контекста |
| `within_group.py` | что даёт кодирование группы strain+Culture | третий источник вероятности, сильнее структурного |
| `final_blend.py` | веса трёх источников | 0.0 структура, 0.3 контекст, 0.7 группа |
| `tuning.py` | категории или tf-idf для контекста | категории. Tf-idf хуже на остовах (15.21M против 13.97M) |
| `calibration.py`, `nested.py` | помогает ли калибровка вероятности | нет. На тех же данных изотоническая калибровка выглядит выигрышной (11.75M), но при честной вложенной проверке проигрывает (14.94M). Платт в пределах шума |
| `matched_feature.py` | что даёт признак «молекула найдена в открытых базах» | заметный выигрыш до подстановки значений |
| `with_literature.py` | что даёт подстановка SI из открытых баз | основной источник улучшения; оценка честная, подстановка только на контрольной части |

Итог для пайплайна (`vacv/pipeline.py`): ExtraTrees на контексте и LightGBM на структуре с
кодированием группы, смешивание вероятностей с весами 0.0 / 0.3 / 0.7, условное среднее с
константой для активных, без калибровки, поверх всего подстановка значений из открытых баз.

## Проверки решения

Отдельная папка `analysis/`: состязательная валидация, аудит утечек, домен применимости,
неопределённость, воспроизводимость. Результаты собраны в `docs/validation.md`, рисунки
в `docs/figures/`.
