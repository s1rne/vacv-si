# Эксперименты

Каждый скрипт запускается как `PYTHONPATH=. uv run python experiments/<имя>.py` и печатает таблицу.
Везде метрика соревнования: MSE на исходной шкале SI. Два разбиения: по остовам Мурко (честная
оценка на новых химических сериях) и случайное (ближе к устройству тестовой выборки).

| скрипт | вопрос | вывод |
|---|---|---|
| `grid.py` | как оценивать средний SI активных | не важно: константа, регрессия в логарифме и регрессия на исходной шкале дают 14.69–14.75M. Всё решает классификатор неактивных |
| `classifier.py` | какая модель и какие признаки | ExtraTrees лучше LightGBM, случайного леса, SVM и логистической регрессии: AUC 0.846 против 0.804–0.832 на остовах |
| `context.py` | помогают ли strain, Culture, Title | да, и сильно: контекст без структуры даёт AUC 0.882 против 0.846 у структуры. Внутри одной публикации серия соединений обычно либо активна, либо нет |
| `blend.py` | как соединить структуру и контекст | смешивать вероятности, а не признаки. Лучший вес 0.2 структуры: MSE 14.04M против 16.93M у структуры и 14.16M у контекста |
| `tuning.py` | категории или tf-idf для контекста | категории. Tf-idf хуже на остовах (15.21M против 13.97M) |
| `calibration.py`, `nested.py` | помогает ли калибровка вероятности | нет. На тех же данных изотоническая калибровка выглядит выигрышной (11.75M), но при честной вложенной проверке проигрывает (14.94M). Платт в пределах шума |
| `within_group.py` | как использовать принадлежность к публикации | доля неактивных в группе как отдельный признак рядом со структурой: 11.03M против 12.06M на случайном разбиении |
| `final_blend.py` | веса трёх источников вероятности | 0.3 контекста и 0.7 группового кодирования: 10.76M. Структурный блок в этой конфигурации не добавляет |
| `with_literature.py`, `matched_feature.py` | что дают открытые базы | подстановка найденных значений и признаки присутствия: 10.77M → 10.22M на случайном разбиении, на лидерборде 8.59M → 7.49M |
| `series_neighbour.py` | помогает ли метка соседнего по номеру соединения из той же статьи | нет. Сосед по номеру даёт AUC 0.725 против 0.965 у модели, в смеси только ухудшает. Сигнал публикации уже забран групповым кодированием |
| `active_value.py` | нужно ли разное среднее активных для найденных и ненайденных | нет, раздельные средние хуже: одно значение 10.22M против 10.25M |

Таблица выше — исторические эксперименты. Их выводы не заменяют оценку текущего
пайплайна: часть старых скриптов использует прежние интерфейсы и порог `>= INACTIVE`
вместо точного равенства, поэтому не используется для нового отбора моделей.

Текущие профили определены в `vacv/inference.py`; единая команда сравнения:

```bash
PYTHONPATH=. uv run python scripts/cv.py --profiles baseline crossfit descriptors context context_half kernel hybrid --seeds 1 --repeats 3
```

Отдельные кандидаты CatBoost: `catboost`, `catboost6`, `catcontext`.
