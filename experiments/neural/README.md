# Нейросетевые эксперименты

Результаты и выводы — в `docs/neural.md`. Здесь только что чем запускать.

Тяжёлое считалось на RTX 3060: `CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=1`.
Порядок устройств обязателен: по умолчанию CUDA сортирует карты по скорости, и индекс 1
попадает на другую карту.

| скрипт | вопрос | окружение |
|---|---|---|
| `folds_export.py` | выгрузить фолды для прогонов в чужом окружении | основное |
| `frozen.py` | сильнее ли замороженный эмбеддинг отпечатков | основное, GPU |
| `controls.py` | не в голове ли дело и не в манере ли записи SMILES | основное, GPU |
| `leak.py` | воспроизводится ли выигрыш символьными n-граммами строки | основное, CPU |
| `tuning.py` | какие шаг обучения и число эпох нужны файнтюнингу | основное, GPU |
| `tuned.py` | файнтюнинг, аугментация, перенос, канонизация | основное, GPU |
| `graphs.py` | GIN и AttentiveFP с нуля | основное, GPU |
| `chemprop_run.py` | D-MPNN (Chemprop 2.3.1) | отдельное: `chemprop` + `torch==2.9.1` |
| `collect.py` | сводная таблица и польза в ансамбле | основное, CPU |

Chemprop тянет `lightning` и `descriptastorus` и конфликтует с `transformers`, поэтому
стоит в отдельном окружении и общается через `data/interim/neural/folds.npz`. Там же нужен
`torch==2.9.1`: по умолчанию ставится сборка под CUDA 13, а драйвер на машине 12.8.

Переменные `CHEMPROP_EPOCHS`, `CHEMPROP_PATIENCE`, `CHEMPROP_CONFIGS` сокращают прогон
Chemprop для проверки, что всё запускается.

Все вероятности складываются в `data/interim/neural/*.npz` и `data/interim/oof/*.npz`,
поэтому `collect.py` пересобирает таблицу, ничего не обучая.
