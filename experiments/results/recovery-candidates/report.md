The candidate sharpens the sentinel probability using
`p**1.2 / (p**1.2 + (1-p)**1.2)` before combining with the training-fold active SI
mean. Three candidates were evaluated on split 3: sharpening 1.2, smoothing 0.8,
and molecular Tanimoto^4 active-SI regression with prior pseudocount 3. Only
sharpening won discovery, and was fixed before running confirmation splits 6–8.
Both other candidates lost on every evaluated split and are rejected.

Confirmation changes the mean from 8,953,685 to 8,821,410 (1.477% improvement).
This is repeated CV on the same 320 observations, not an independent holdout or
proof of leaderboard improvement. No Kaggle submission was sent.

All OOF arrays and metrics are included. Historical splits 4–5 were run after
confirmation, without changing the candidate. Do not compare these clean scores
as an apples-to-apples model ablation against older lookup-assisted metrics.
