# Проверки решения

Код проверок, результаты которых собраны в `docs/validation.md`, рисунки в `docs/figures/`.
Запуск: `PYTHONPATH=.:analysis uv run python analysis/<имя>.py`.

`common.py` держит общую загрузку и кэш вероятностей; кэш лежит в `analysis/cache/`
и в репозиторий не входит.

| скрипт | что проверяет |
|---|---|
| `oracle.py` | восстановление скрытых меток теста из `CC50_uM` и `IC50_uM_VACV` (эталон проверки, в модель не попадает) |
| `decompose.py` | разложение ошибки сабмита по группам строк |
| `adversarial.py` | отличимы ли строки теста от строк обучения |
| `public_split.py`, `split_check.py` | какая часть теста даёт публичный счёт |
| `lb_noise.py` | разрешающая способность публичной оценки |
| `cv_vs_lb.py` | пять поколений модели: кросс-проверка против лидерборда |
| `first_submission.py` | какой моделью был первый сабмит |
| `leakage.py` | происхождение литературных значений, близость признаков к запрещённым колонкам, дубликаты |
| `target_encoding.py` | вклад строки в собственное кодирование группы |
| `forbidden_proxy.py` | цена отказа от признаков, повторяющих запрещённые колонки |
| `ablation.py` | вклад групп признаков, измеренный исключением |
| `interpret.py` | SHAP, подструктуры, дескрипторы, остовы Мурко |
| `chemotype.py` | проверка химического вывода прямым счётом по SMARTS |
| `domain.py`, `domain_split.py` | домен применимости в трёх определениях |
| `calibration_test.py`, `uncertainty.py` | калибровка вероятности, бутстреп, конформные интервалы |
| `figures.py`, `figure_chemistry.py` | рисунки в `docs/figures/` |
